# 📄 Editais URE Adamantina - Unidade Regional de Ensino de Adamantina

![Status](https://img.shields.io/badge/Status-Concluído-success)
![Tecnologias](https://img.shields.io/badge/Tecnologias-HTML5%20%7C%20CSS3%20%7C%20JavaScript-blue)

O **Editais URE** é um sistema web estático desenvolvido para armazenar, organizar e disponibilizar arquivos de editais de determinadas seções da Unidade Regional de Ensino (URE). O projeto foi construído como um modelo (template) escalável, facilitando a divisão por categorias e permitindo que os usuários encontrem publicações rapidamente através de filtros de busca e ordenação por data.

## 🎯 Objetivo do Projeto

O principal objetivo deste sistema é modernizar e simplificar o acesso à informação. Através de uma interface responsiva e alinhada à identidade visual do Estado (SP.GOV.BR), o sistema garante que professores, agentes e o público em geral encontrem editais de forma intuitiva, sem a necessidade de navegar por listas extensas e desorganizadas.

## ✨ Principais Funcionalidades

* **🔍 Busca em Tempo Real:** Filtro inteligente que pesquisa editais pelo assunto ou pela data assim que o usuário digita.
* **📅 Ordenação Dinâmica:** Botão interativo na tabela para alternar a exibição dos editais da data mais recente para a mais antiga (e vice-versa).
* **📄 Paginação Automática:** O sistema quebra listas longas (a cada 11 itens) em páginas organizadas automaticamente pelo JavaScript, mantendo a interface limpa.
* **🖱️ Navegação Dropdown:** Menus em formato de "cascata" acionados por clique, com suporte a submenus aninhados para organizar a estrutura institucional.
* **⬇️ Download Direto:** Botões formatados que forçam o navegador a baixar os arquivos PDF diretamente para a máquina do usuário.
* **📱 Totalmente Responsivo:** Interface que se adapta perfeitamente a monitores widescreen, tablets e smartphones.
